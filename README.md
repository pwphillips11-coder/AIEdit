# AIEdit

A modern AI-inspired image editor built with Next.js and TypeScript.

## Features

- Upload and preview images
- AI prompt-driven editing presets
- Brightness, contrast, saturation, blur, and hue controls
- Before/after split view
- Undo/redo history
- PNG export
- Responsive UI

## Getting started

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Available scripts

```bash
npm run dev
npm run build
npm run start
npm run lint
```
